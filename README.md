# Starter kit de IA — DMI 2026

Guía de materiales y recursos para usar **agentes de IA** en el desarrollo de
software de la materia Desarrollo Móvil Integral (Ingeniería en Desarrollo y
Gestión de Software, UTEZ).

## Por qué existe esta guía

En la industria ya casi nadie programa sin IA. Pero quien sabe usarla no le pide
"hazme la app" y copia lo que salga: la **dirige**, **revisa** lo que genera y
**responde** por el resultado. La IA es una herramienta; la persona que entrega
el código sigues siendo tú.

Esta guía te lleva de tener la herramienta instalada a trabajar con ella como se
trabaja en un equipo real.
